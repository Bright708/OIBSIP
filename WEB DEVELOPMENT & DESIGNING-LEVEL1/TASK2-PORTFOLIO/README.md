# Personal Portfolio Website

## Objective

The objective of this project is to develop a personal portfolio website showcasing professional skills, background, technical projects, and contact channels in a clean, modern, and accessible digital resume format.

## Steps Performed

1. Structured the page using semantic HTML5 elements across dedicated sections including Hero, About, Skills, Projects, and Contact.
2. Formatted a personal profile card with current availability status, key stats, and an introduction.
3. Created an organized skills grid presenting frontend and full-stack development capabilities.
4. Curated project showcase cards detailing featured technical work with live repository links and descriptive badges.
5. Implemented responsive styling using CSS custom properties, fluid typography via clamp functions, and breakpoint rules for multiple display sizes.
6. Added progressive scroll animations using JavaScript and IntersectionObserver with unobserve behavior to ensure performance.
7. Ensured accessibility by incorporating semantic landmarks, descriptive alt attributes, aria-labels, and visible focus states.

## Tools Used

- HTML5: Semantic markup and page structure
- CSS3: Custom properties, CSS Grid, Flexbox, responsive media queries, and styling
- JavaScript (ES6): IntersectionObserver API for scroll animations
- Modern Web Browser: Responsive testing and layout validation

## Outcome

A fully responsive, performant personal portfolio website that delivers a professional presentation of developer qualifications, projects, and contact avenues across all modern device viewports.
