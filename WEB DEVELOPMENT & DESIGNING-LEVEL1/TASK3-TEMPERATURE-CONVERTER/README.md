# Thermal Vector - Temperature Converter

## Objective

The objective of this project is to build an interactive temperature conversion web application that converts numeric temperature values between Celsius, Fahrenheit, and Kelvin scales accurately with real-time feedback and validation.

## Steps Performed

1. Designed a clean, instrumentation-style user interface card with input fields, scale selectors, dynamic status badges, and result display cards.
2. Built the semantic HTML5 structure with clear accessibility attributes, input constraints, and action controls.
3. Styled the interface using CSS3 with custom variables, glassmorphic container aesthetics, dark theme color schemes, and responsive layout scaling.
4. Implemented temperature conversion logic in JavaScript covering Celsius, Fahrenheit, and Kelvin scales, including absolute zero limit enforcement (-273.15 deg C).
5. Added real-time input event listeners, validation messaging for invalid or out-of-range numeric entries, and precision number formatting.

## Tools Used

- HTML5: Form controls, accessibility semantics, and structured layout
- CSS3: Custom properties, Flexbox, Grid, transitions, and dark UI styling
- JavaScript (ES6): Mathematical conversion formulas, event handling, and DOM manipulation
- Google Fonts: Inter and JetBrains Mono typography
- Font Awesome: Iconography for controls and indicators

## Outcome

A reliable, responsive temperature conversion tool that provides instant, validated multi-unit temperature calculations with a clean modern user experience.
