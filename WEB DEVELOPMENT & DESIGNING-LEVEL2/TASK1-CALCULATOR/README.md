# TE-84 Lab Instrument - Calculator

## Objective

The objective of this project is to build a functional, visually styled calculator web application that performs standard arithmetic operations with precision, clear user feedback, and keyboard/mouse interaction support.

## Steps Performed

1. Designed an industrial laboratory instrument interface featuring a recessed digital display panel, metadata badges, and a 20-key primary matrix.
2. Structured the keypad layout and display screen using semantic HTML5 elements with appropriate data attributes for operations and values.
3. Styled the chassis, recessed screen, button states, and typography using CSS3 Grid, Flexbox, custom box shadows, and monospace fonts.
4. Programmed calculation logic in JavaScript using event delegation to handle addition, subtraction, multiplication, division, percentage, sign toggling, and decimal inputs.
5. Implemented state tracking to maintain the running expression preview, prevent consecutive operator errors, handle division by zero, and support backspace deletion.

## Tools Used

- HTML5: Structural chassis, display containers, and interactive keypad elements
- CSS3: CSS Grid, custom properties, layered shadows, hover and active states
- JavaScript (ES6): Arithmetic evaluation, state machine logic, and DOM updates
- Google Fonts: Chakra Petch, JetBrains Mono, and Share Tech Mono

## Outcome

A distinctive, responsive, and robust digital calculator with reliable arithmetic processing, expression history previews, and smooth tactile feedback across desktop and mobile screens.
