# Oasis Infobyte Internship (OIBSIP) - Web Development and Designing

## Objective

The objective of this repository is to consolidate all projects completed during the Oasis Infobyte Web Development and Designing Internship program across Level 1 and Level 2 tracks. Each project demonstrates core web standards, frontend engineering principles, responsive layout design, and client-side logic.

## Steps Performed

1. Reviewed internship requirements across all allocated Level 1 and Level 2 development tasks.
2. Developed Level 1 foundational frontend projects including a branded landing page, a personal portfolio website, and an interactive temperature converter.
3. Built Level 2 advanced interactive projects including a scientific lab calculator, a historical tribute archive, a persistent task flow to-do list, and a client-side authentication system with SHA-256 hashing.
4. Structured each project within an isolated task directory complete with self-contained assets, scripts, stylesheets, and documentation.
5. Standardized project documentation across all task folders, providing comprehensive README files specifying the objective, steps performed, tools used, and outcome.

## Tools Used

- HTML5: Semantic markup, accessible structures, and layout standards
- CSS3: Custom properties, Flexbox, CSS Grid, media queries, and animations
- JavaScript (ES6): Client-side application logic, event delegation, and asynchronous handling
- Web Crypto API: Browser-native SHA-256 hashing for authentication
- LocalStorage API: Persistent client-side data storage
- Font Awesome and Google Fonts: Typography and visual UI iconography
- Visual Studio Code: Code authoring and project management
